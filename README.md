# IndabaX ML Basics Practical

A 30-minute, beginner-friendly hands-on session covering the essential steps of building a machine learning model — plus a practical introduction to using Kaggle. Built for an IndabaX Deep Learning Indaba event.

## Contents

- `IndabaX_ML_Basics_Practical.ipynb` — the practical notebook, ready to run top to bottom

## What You'll Learn

- The 8-step machine learning workflow (problem → data → EDA → split → train → evaluate → iterate → share)
- How to explore, clean, split, and scale a dataset
- How to train and evaluate simple classifiers (Logistic Regression, Decision Tree)
- How to recognise overfitting vs. underfitting
- How to get started on Kaggle: datasets, competitions, and free cloud notebooks

## Requirements

- Python 3.8+
- Jupyter Notebook or JupyterLab
- `numpy`, `pandas`, `matplotlib`, `seaborn`, `scikit-learn`

## Setup

```bash
git clone <this-repo-url>
cd <this-repo-folder>
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
jupyter notebook IndabaX_ML_Basics_Practical.ipynb
```

The notebook uses scikit-learn's built-in breast cancer dataset, so it runs identically for everyone with no downloads or internet dependency — handy for a live workshop.

## Agenda (~30 min)

1. What is Machine Learning? *(2 min)*
2. The ML workflow *(3 min)*
3. Hands-on: build a model step-by-step *(18 min)*
4. Using Kaggle *(5 min)*
5. Wrap-up & next steps *(2 min)*

## After the Session

- Repeat the same workflow on the [Kaggle Titanic competition](https://www.kaggle.com/c/titanic) dataset
- Try Kaggle Learn's free "Intro to Machine Learning" micro-course
- Look for African-context datasets and competitions (e.g. on Zindi) to practice further
